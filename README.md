# thesis-rag

Question answering over my Master's thesis ("A Web-Scale Analysis of Trends in AI-Generated and SEO Spam Content", Bauhaus-Universität Weimar) with retrieval-augmented generation, orchestrated as a LangGraph workflow.

## How it works

1. `ingest.py` splits the PDF into overlapping chunks (with page numbers) and builds a TF-IDF index. It runs offline.
2. `graph.py` defines a LangGraph state graph: **rewrite query -> retrieve -> grade relevance -> generate** or, if nothing relevant was found, retry once and then **ask for clarification**.
3. `rag_nodes.py` holds the node logic. Answers are generated by Claude from the retrieved context only, with page citations, when `ANTHROPIC_API_KEY` is set. Without a key it falls back to returning the most relevant sentences.

## Run it

```
pip install -r requirements.txt
python ingest.py path/to/thesis.pdf
python test_rag.py
export ANTHROPIC_API_KEY=...   # optional
python ask.py
```

## Status and limitations

- Retrieval and routing logic are covered by `test_rag.py` (5 checks, all passing on the thesis).
- Retrieval is lexical (TF-IDF), not embedding based. A natural next step is swapping in a sentence-embedding model and comparing retrieval quality.
- No formal answer-quality evaluation has been run yet.
